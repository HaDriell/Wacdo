# Projet de Workshop pour Coursenia (Formation Fullstack Spring + Angular)

Le but du projet est de réaliser une application web pour modéliser les affectations des employés de Wacdo, une société fictive de restauration rapide. Une synthèse du sujet est disponible sur le repository.
